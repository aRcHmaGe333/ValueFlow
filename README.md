ValueFlow: Universal IP Revenue Sharing System
PRIOR ART DISCLOSURE - AUGUST 29, 2025, 11:45 PM CEST (Stockholm)

## What it does

People who want to build on someone else's work often face licensing barriers. Meanwhile, the original creator may earn nothing from later improvements.

ValueFlow proposes a way to make reuse easier and share the value created with the people whose work made it possible. Sharing can happen automatically or with minimal manual handling. The amounts, payment arrangements and technical systems can vary; none of those choices defines the whole idea.

For the complete specification including definitions, implementation variants, edge cases, and technical architecture details, see universal_ip_system.md.
